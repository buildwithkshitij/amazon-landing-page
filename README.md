# Amazon Landing Page Clone

A frontend clone of the Amazon homepage built using HTML and CSS.
This project was created to practice webpage layout, styling,
navigation bars, product cards, and footer design.

## Features

- Amazon-inspired navigation bar
- Delivery location section
- Search bar with category selector
- Account and orders section
- Shopping cart section
- Hero banner
- Product category cards
- Multi-column footer

## Technologies Used

- HTML5
- CSS3
- Font Awesome

## Project Structure

- `index.html` - Website structure
- `style.css` - Website styling
- Image files - Logo, hero banner, and product cards

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or your browser.
